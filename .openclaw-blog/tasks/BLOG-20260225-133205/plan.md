- 팀 내 가이드 문서를 만들려는 리드/시니어
- 빠른 실전 팁(권한, 모델, 도구, 단축키)을 원하는 사용자

intent:
- 사용자 제공 팁을 기반으로 검증된 실전 가이드를 만든다.
- 위험한 설정(bypass 계열)과 안전한 대안을 함께 제시해 오남용을 줄인다.
- 바로 적용 가능한 체크리스트 + 치트시트 제작 흐름까지 제공한다.

outline:
1) 왜 지금 Claude Code 운영 팁이 필요한가
   - 단순 사용법이 아니라 “팀 운영 관점”에서의 재현성/안전성 문제 제기
2) 먼저 알아둘 4축 프레임
   - 모델 선택(opusplan 포함)
   - 권한/보안(위험 옵션과 경계선)
   - 도구 로딩 전략(tool_search lazy loading)
   - 입력/편집 생산성(단축키, output-style)
3) 실전 팁 12가지 (핵심 본문)
   - 각 팁을 “언제 쓰나 / 어떻게 설정하나 / 주의점” 3단 구조로 정리
4) 위험 옵션 심화
   - bypass-permissions 계열 사용 시 리스크 시나리오
   - 안전한 대체 흐름(승인 경계, 스코프 제한, 로그 확인)
5) 단축키/치트시트 섹션
   - 자주 쓰는 단축키를 상황별(탐색/편집/실행)로 재구성
   - 이미지 치트시트 생성 아이디어(초안 프롬프트 포함)
6) 팀 적용 가이드
   - 개인 설정 → 팀 표준으로 옮기는 최소 체크리스트
   - 온보딩 문서에 넣을 1페이지 템플릿
7) 마무리
   - 오늘 바로 적용할 3가지 액션
